# MATBOT
I made a bot. It basically solves math problems, but it also has many useless features, such as useless facts, random facts, cat facts, jokes, etc. 
Here are all the available commands:
1. MatBot solve: It solves math problems. It can solve for powers, parentheses, equations, basic calculation, and basic arithmetic.
2. MatBot cat fact: It just gives a random cat fact.
3. MatBot joke: It gives a random joke.
4. MatBot help: It shows all the available commands.
5. Matbot ping: It checks the bot's latency.
6. Matbot random: It gives random motivational sentences that are really not motivational.
7. Matbot ideas: It just gives a random idea.
8. Matbot ASCII: It just gives random ASCII art in one line.
9. Mabot facts: It just gives a random useless fact.
